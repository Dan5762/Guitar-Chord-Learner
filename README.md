# Guitar Chord Progression Learner

An interactive web application for learning guitar chord progressions through visual harmonic maps and fretboard diagrams.

## Features

### 🎵 Harmonic Map Visualization
- **Circle of Fifths**: Interactive circular representation of harmonic relationships
- Click chords to navigate through harmonic progressions
- Visual feedback showing chord connections and relationships
- Audio playback for selected chords

### 🎸 Interactive Fretboard
- Real-time fretboard diagrams showing finger positions
- Current chord and next chord preview
- Accurate fret patterns with finger numbering

### 📚 Comprehensive Chord Library
- Major, minor, maj7, min7, and dim7 chords
- All 12 keys with proper harmonic frequencies
- Draggable chord cards for easy interaction

### 🎵 Chord History & Navigation
- Track the last 3 played chords
- Click history items to revisit previous chords
- Visual indication of current chord in history

### 📱 Mobile Responsive
- Touch-friendly interface for mobile devices
- Adaptive layout for different screen sizes
- Tab-based navigation for organized workflow

## How to Use

1. **Select a View**: Choose "Circle of Fifths" from the dropdown
2. **Navigate Chords**: Click on any chord in the harmonic map to select it
3. **View Diagrams**: Switch to the "Diagram" tab to see fretboard positions
4. **Explore Library**: Use the "Chords" tab to browse all available chords
5. **Track Progress**: Monitor your chord history in the bottom panel

## Getting Started

Simply open `index.html` in a modern web browser. No installation or build process required.
